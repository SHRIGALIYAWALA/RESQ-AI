# Production Build Prompt

Use this prompt with an engineering agent when extending RESQ-AI:

> Make RESQ-AI production deployable without paid infrastructure. Preserve the existing FastAPI, SQLAlchemy, local-first AI, human-approval, and tenant-isolation architecture. Use PostgreSQL in production and keep SQLite only for demo/tests. Add an idempotent migration path, fail-fast production configuration validation, JWT/OIDC-ready role-based authorization, tenant-scoped queries for every entity, TLS termination, health/readiness/provider probes, encrypted/off-host backups with restore drills, bounded notification retries with a local webhook or SMTP fallback, and explicit operator approval before delivery or escalation. Add authenticated camera and sensor gateway contracts with validation, ingestion audit events, deduplication/idempotency, rate limits, and reviewable hazard triggers. Add structured audit records for authentication, data changes, incident state changes, notifications, escalation, and operator decisions. Add realistic fire, medical, evacuation, device-failure, notification-failure, tenant-isolation, backup/restore, and health-check tests. Do not claim emergency dispatch, medical diagnosis, structural certification, or production readiness unless the relevant infrastructure and tests are actually deployed and verified. Document all secrets, TLS certificates, retention, backup, monitoring, and incident-response responsibilities. Run syntax checks, focused tests, and the full test suite before reporting completion.
> Deploy and verify every requirement on the target host: install a no-cost Docker Engine where licensing permits, start PostgreSQL, issue a trusted TLS certificate, connect real camera and sensor gateways over HTTPS, test the self-hosted notification relay and failure fallback, schedule encrypted off-host backups, execute and document a restore drill, run the complete test suite against PostgreSQL, and perform signed security and operational acceptance testing. Never substitute a mock for evidence of a real integration. Return a deployment manifest, commands run, test results, unresolved risks, rollback steps, and an explicit production go/no-go decision.
